About This Tool

This free converter transforms HOL calendar files into standard formats you can use in calendar and spreadsheet apps. File processing is fully client-side, so your data stays in your browser.

Supported Input and Output

  • Input: .hol calendar files
  • Output: .ics (iCalendar), .csv, and .json
  • Compatibility: Google Calendar, Apple Calendar, Outlook, Excel, and Google Sheets

How to Convert a HOL File

  1. Upload or drag a .hol file into the converter.
  2. Review parsed categories and event counts in the preview.
  3. Select ICS, CSV, or JSON, then download the converted file.
